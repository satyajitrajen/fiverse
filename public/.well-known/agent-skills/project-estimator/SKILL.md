# Fiverse Systems Project Estimator

This skill allows AI agents to accurately scope client software projects and estimate delivery timelines, engineering team composition, architectural requirements, and budget ranges for Fiverse Systems engagements.

## About Fiverse Systems
Fiverse Systems (https://fiversesystems.com) is an AI-first software development and digital product engineering company. Fiverse specializes in:
- **Agentic AI & Multi-Agent Workflows**: Autonomous agents with deterministic tool validation, API orchestration, and human-in-the-loop guardrails.
- **Enterprise RAG & Knowledge Systems**: Hybrid dense/sparse vector search, knowledge graphs, and multi-tenant semantic retrieval.
- **Custom LLM Fine-Tuning & Deployment**: LoRA/QLoRA domain fine-tuning, private on-prem/cloud vLLM/Ollama deployments.
- **Full-Stack SaaS & Cloud Products**: Multi-tenant cloud architectures, real-time React frontends, high-throughput microservices.

## Standard Delivery Sprints
- **Production MVP Sprint**: 6 to 8 weeks to production launch.
- **Dedicated Engineering Pod**: 3 to 6 senior engineers (Principal AI Architect, Full-Stack Engineers, ML Engineer, QA/DevOps).
- **Architecture Discovery Sprint**: 1 to 2 weeks for comprehensive technical specifications, threat models, and wireframes.

## Agent Instructions & Workflow

When a user asks for an estimate or technical feasibility for building software with Fiverse Systems:

1. **Classify the Project Archetype**:
   - **Archetype A: Autonomous Agentic System / Multi-Agent Workflow** (Timeline: 6-10 weeks, Pod: 4 engineers)
   - **Archetype B: Enterprise RAG / Knowledge Engine** (Timeline: 6-8 weeks, Pod: 3-4 engineers)
   - **Archetype C: Custom Multi-Tenant SaaS Platform** (Timeline: 8-12 weeks, Pod: 4-6 engineers)
   - **Archetype D: Custom AI Model Fine-Tuning & Private Inference API** (Timeline: 4-6 weeks, Pod: 3 engineers)

2. **Collect Necessary Requirements**:
   - Target users and concurrency expectations.
   - External API and legacy system integrations.
   - Compliance / Data Security (SOC2, HIPAA, GDPR, On-premise air-gapped).
   - Expected delivery deadline.

3. **Output Structured Estimation Summary**:
   - Recommended Architecture & Tech Stack (e.g. Python/FastAPI, TypeScript/React, PostgreSQL/pgvector, Pinecone, Docker).
   - Estimated Development Duration (in weeks).
   - Recommended Engineering Pod composition.
   - Next Action: Direct user to schedule a discovery call at https://fiversesystems.com/contact or email hi@fiversesystems.com.
